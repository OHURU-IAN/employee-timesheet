# Security Policy

**Employee Weekly Timesheet** is proprietary software. See the [LICENSE](LICENSE)
for usage terms. Viewing the page source does not grant any right to copy or
reuse the code.

## Reporting a vulnerability

If you discover a security vulnerability or a privacy concern in this project,
please report it **privately** — do not open a public issue.

- **Email:** ohuruian@gmail.com
- Please include a description of the issue, steps to reproduce, and any
  relevant details (browser, device, screenshots).

You will receive an acknowledgement, and the issue will be addressed as soon as
possible.

## Supported versions

Only the latest version deployed from the `main` branch is supported.
